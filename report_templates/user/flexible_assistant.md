## 模板说明

# 灵活助手

**一句话说明：** 不套固定章节，围绕用户问题组织一份自然、克制、便于继续追问的舆情分析。

| 项目 | 说明 |
| --- | --- |
| 适合场景 | 日常研判、多轮追问、需要先看结论再逐步展开 |
| 预计篇幅 | 约 700～1100 字，按材料多少收缩 |
| 适用读者 | 需要快速理解事件和下一步关注重点的业务人员 |

## 这种模板的特点

- 先直接回应问题，再按需要使用小标题或短段落展开。
- 只保留与当前主题有关的检索材料，不堆砌热点和背景百科。
- 可以同时呈现事实、舆情特点和研判，但不强制出现固定章名。
- 用户提出“再具体一点”“换个角度”时，便于在同一会话中继续细化。

## 不适用的情况

如果需要归档、正式报送或严格对照固定章节，应改选四段式报告或决策备忘录；如果只需要几条结论，应选择要点清单。

## 灵活助手（示例）

> 真实事件版式示例，仅用于展示报告结构与表达方式；示例内容不作为实时研判结论，正式报告以本次检索和会话材料为准。

### 俄乌冲突舆情态势研判

冲突升级后，军事行动、对俄制裁与对乌援助、人道救援、能源粮食安全和核设施安全进入国际公共议程。相关信息高度碎片化，战场消息、外交表态与网络评论相互叠加，任何即时结论都需要核对发布时间、原始出处和发布主体。

**主要态势**

国际讨论一方面关注冲突走向、停火条件及安全安排，另一方面关注援助政策、制裁效果和外溢影响。黑海运输、能源价格、难民安置以及扎波罗热核电站安全等议题，具有较高公共风险敏感度。

**舆情特点**

- 俄乌双方对战果、损失和责任归属的表述差异明显，单方消息不能直接视为共同事实。
- 社交平台常见旧图重发、片段化视频和情绪化标题，传播速度快于核验速度。
- 不同国家媒体受政策立场和受众关切影响，议题选择和叙事框架存在差异。

**研判与关注**

舆情热度可能随重大军事行动、援助政策或谈判信号快速波动。研判应严格区分已证实事实、单方主张与分析判断，重点跟踪人道局势、核安全、粮食与能源外溢影响。

## 生成要求

## 选用后系统会怎么做

系统仍按已勾选的数据源检索舆情库和知识库，再用自然叙述组织结果。模板只规定表达方式，不改变检索范围，也不替用户补充未提供的事实。

## 生成要求

1. 首段直接回答用户问题；必要时使用 2～4 个小标题，避免机械套用“四段式”。
2. 每个判断都紧跟材料依据；没有依据时写“现有材料未提供”，不得猜测数字、时间或机构态度。
3. 把检索结果融入正文，合并重复信息，优先保留对当前问题有用的内容。
4. 预览仅供学习版式，不得复制其中的俄乌冲突事件名称、报告标题、日期、事实、数字或研判结论。
5. 只输出最终 Markdown 正文，不输出模板说明、生成要求、思考过程或“以下是报告”等元话语。
