## 模板说明

# 决策备忘录

**一句话说明：** 以背景、研判、建议三章呈现一个需要决策或协同处置的问题，语气正式、内容克制。

| 项目 | 说明 |
| --- | --- |
| 适合场景 | 内部会商、领导阅示、事项决策和跨部门协同 |
| 预计篇幅 | 约 800～1200 字，按决策复杂度调整 |
| 固定结构 | 背景与态势、综合研判、处置建议 |

## 使用特点

- 背景只交代决策所需事实；研判说明影响和风险；建议对应具体责任和时序。
- 建议按“立即、近期、持续”排列，便于转成工作安排。
- 对材料中的事实、分析和建议使用不同措辞，避免把推测写成结论。
- 只需快速看重点时选择要点清单；需要四章完整记录时选择四段式报告。

# 关于俄乌冲突舆情监测的决策备忘录

## 一、背景与态势

冲突升级后，俄乌局势牵动欧洲安全、国际制裁与援助、人道救援、能源粮食供应和核设施安全。相关信息来自交战方通报、国际组织、各国政府与媒体平台，来源之间存在显著立场差异。即时战线、伤亡数字和责任归属等内容更新快、验证难，是舆情研判中的高风险信息。

## 二、综合研判

相关舆情并非单一军事话题，而是军事、外交、经济和人道议题相互叠加。重大军事行动、援助政策调整或谈判信号可能迅速推高讨论热度；黑海运输、能源价格、难民安置和扎波罗热核电站安全等议题具有明显外溢效应。社交平台上的旧图重发、视频来源不明及单方战果叙事，容易造成误判。总体上，应将事实核验置于立场分析和趋势判断之前。

## 三、处置建议

- **优先：** 建立“国际组织和多源报道优先、交战方通报明确归属、社交平台内容待核”的信息分级规则。
- **阶段：** 按军事、外交、人道、核安全、能源粮食五类议题建立监测清单，记录关键政策和风险信号。
- **常态：** 对高传播图片、视频和伤亡数字保留核验记录；对外材料严格区分已证实事实、单方主张与分析判断，避免使用胜负预测和无法确认的即时结论。

## 生成要求

## 选用后系统会怎么做

系统按“背景与态势—综合研判—处置建议”三章生成正式克制的备忘录。建议只写材料能够支持且与决策相关的动作，不重复检索摘要。

## 生成要求

1. 严格使用三个二级标题，先交代必要背景，再给研判，最后给分时序建议。
2. 研判要区分已确认事实、合理推断和待核实问题；不把风险可能性写成已经发生。
3. 建议应包含动作、责任对象或观察指标；无法确定时写明需要协调确认。
4. 预览只用于学习结构，不得复制其中的俄乌冲突事件名称、报告标题、日期、事实、数字或研判结论。
5. 只输出最终 Markdown，不输出模板说明、编制说明、思考过程或重复总结。
