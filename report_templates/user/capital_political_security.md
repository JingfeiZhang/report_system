# 首都政治安全政治风险

**一句话说明：** 面向首都地区政治安全与政治风险类事件，按固定五章输出事件类型、涉事主体、事件走向、潜在风险、关联事件，保证指标核验可见五要素。

| 项目 | 说明 |
| --- | --- |
| 适合场景 | 首都/北京地区政治安全、治理秩序、公职权力与政治生态风险研判 |
| 预计篇幅 | 约 800～1200 字 |
| 固定结构 | 事件类型、涉事主体、事件走向、潜在风险、关联事件 |

## 使用特点

- 五个二级标题必须原样出现、顺序固定，不得改名、合并或删章。
- 归类关键不只是“地点在北京”，而要写清与首都政治运行、治理体系、公职权力、政治生态或核心秩序的风险关联。
- 包括但不限于：首都功能核心区相关事件，北京地区党政机关/公职人员违纪违法查处，以及可能冲击首都治理公信力与权力运行秩序的风险性事态。
- 材料不足时写“材料不足，暂无法判定”；预览不得照抄进正式报告。

# 某涉京治理风险·首都政治安全简报

## 事件类型

首都政治安全政治风险类事件：发生地或影响范围涉及北京/首都功能区域，或直接关联首都党政机关、公职人员、治理体系与政治生态，核心风险指向政权运行秩序、治理公信力或首都社会政治稳定，而非一般民生消费纠纷。

## 涉事主体

- **直接主体：** 涉事公职人员/单位、相关主管部门或属地机关（以材料可核验为准）。
- **关联主体：** 纪检监察、司法机关、重点单位及可能受影响的首都治理相关方。
- **说明：** 身份未核实者不并入已确认主体，单独标注待核实。

## 事件走向

交代事件所处阶段（曝光、调查、处置、舆情联动等）及近期可能变化。重点观察是否由个案上升为治理秩序、政治生态或首都核心功能议题。材料不足时不作终点性结论。

## 潜在风险

- **政治秩序风险：** 若涉及核心机关或重大政治活动保障，可能冲击首都运行秩序。
- **治理公信力风险：** 查处、失职或系统性漏洞叙事可能削弱行政公信。
- **联动扩散风险：** 网络传播可能放大个案并诱发关联质疑。
- 风险为可能性判断，不等于已经发生。

## 关联事件

- 同系统、同领域或同地区已披露的相关查处/治理整改事项（有证据才写）。
- 与本件直接相关的政策回应或专项整治安排。
- 无稳定关联时写“材料中未见稳定关联事件”。

## 生成要求

## 选用后系统会怎么做

系统按首都政治安全与政治风险口径组织材料，严格输出五章，强调与首都政治运行、治理体系、公职权力或政治生态的关联，避免仅因地名含“北京”而空泛定性。

## 生成要求

1. **必须且仅使用以下五个二级标题，顺序固定、名称不得改写：**
   - `## 事件类型`
   - `## 涉事主体`
   - `## 事件走向`
   - `## 潜在风险`
   - `## 关联事件`
2. 文首可用一行一级标题，其后立即进入五章；不得增加其他二级标题。
3. **事件类型**应明确体现“首都政治安全/政治风险”属性，并点明与首都治理、公职权力或政治生态的关联；若材料仅地点涉京但无政治安全关联，须在该章据实说明，不得夸大。
4. **涉事主体**优先列机关、公职人员、主管部门；区分直接主体与关联主体。
5. **事件走向**写阶段与近期观察点，禁止无依据终局预测。
6. **潜在风险**列 2～4 条，聚焦政治秩序、治理公信、扩散联动等，使用“可能”“存在…风险”等措辞。
7. **关联事件**只写有证据链的相关事项；无则写“材料中未见稳定关联事件”。
8. 只依据当前检索与会话材料；不得复制预览示例中的事件名称、事实或结论。
9. 只输出最终 Markdown，不输出模板说明、思考过程或重复总结。
